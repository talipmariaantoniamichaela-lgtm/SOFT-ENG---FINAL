Help & Documentation

1. System Overview

Motion Reader is a real-time computer vision system that tracks human movement, classifies postures, identifies gestures, and streams timestamped actions directly into the Motion Terminal.

2. Source Selection

  • Live Camera: Select the "Live Camera" card or use the bottom camera selector dropdown. Automatically requests browser webcam permission.
  • Upload Video: Select the "Upload Video" card to load an MP4, MOV, AVI, or WebM video file. When in video mode, seek bar, play/pause, and restart controls appear automatically.

3. Skeletal Tracking Overlay

  • Bones: Electric-blue lines indicate anatomical skeletal links between joints.
  • Joints: Two-tone circular markers represent detected landmarks (shoulders, elbows, wrists, hips, knees, ankles).
  • Hands: Detailed 21-point hand skeleton and finger joints are tracked when visible.

5. Duplicate Suppression

The system uses stateful hysteresis and temporal sliding windows to prevent spamming duplicate events. Sustained postures (like Standing) only log when transitioning into or out of that posture.
